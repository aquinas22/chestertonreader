# The Mind of Chesterton

An illustrated, interactive library of G. K. Chesterton: free Project Gutenberg editions, a focused reading room, contextual dictionary, passage guide, quotation treasury, thematic atlas, and intellectual timeline.

## Run locally

Serve the directory with any static server, for example:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

The catalogue and dictionary use public APIs at runtime. The original curated bibliography remains available as a graceful catalogue fallback if the Gutenberg API is unavailable.

## Sources and rights
